# Skill: SOXL 趋势择时与精准 Covered Call 增强策略

## 1. 技能概述 (Overview)
本技能定义了在交易三倍做多半导体 ETF（`SOXL`）时，如何以**正股趋势择时为主驾驶**、以**挑时机卖出备兑看涨期权（Covered Call）为副驾驶**的完整标准作业程序（SOP）。
- **核心哲学**：少即是多（Less is More）。Covered Call 的核心不在于“每周勤快收租”，而在于**“绝大多数时候忍住不卖”**，仅在短期暴涨后、大概率进入震荡歇息的窗口期精准出手。
- **适用标的**：持仓标的为 `SOXL`（每张期权需至少持有 $100$ 股正股），观察指标标的为 `QQQ`（纳指 100 ETF）与 `SOXX`（一倍半导体 ETF）。

---

## 2. 底层基础：正股择时原则 (Underlying Timing Rules)
期权仅提供收益增厚，账户长期复利的核心来自于避开深坑的正股择时：
1. **趋势判断**：以 `QQQ` 是否处于年线（如 $250$ 日均线）上方，结合半导体板块（`SOXX`）从高点回撤的幅度作为核心依据。
2. **仓位切换**：
   - **主升/反弹期**：趋势良好或触发深跌反弹条件时，满仓持有 `SOXL`。
   - **防守/退守期**：趋势走坏时，严格按照底层规则退守至一倍 ETF（`SOXX`）或空仓持有现金，规避如 2022 年级别的毁灭性回撤。
3. **主次纪律**：**永远由正股择时规则决定股票的买卖**，绝不允许因为卖了期权而改变正股的去留。

### 底层正股择时参数表（SOXX/SOXL V27.0 四季状态机）

- **回撤计算基准**：以 1 倍半导体 ETF（SOXX）距离过去 252 个交易日最高收盘价（创新高则上移）的跌幅为准。
- **宏观牛熊开关**：以 QQQ 年线（MA252）划分牛熊模式。

| 状态 / 阈值维度 | 牛市参数 (QQQ 在年线上) | 熊市参数 (QQQ 在年线下) | 触发动作与目标仓位 |
| :--- | :--- | :--- | :--- |
| **常态持仓** | 99% SOXL (3x) | 50% SOXX (0.5x) | 趋势健康时牛市满仓三倍进攻，熊市半仓一倍现货防守 |
| **高位逃顶线** | 距高点 95% 内 + 2.0倍量 + 收阴 | 距高点 95% 内 + 2.0倍量 + 收阴 | 当日成交量达 60 日均量 2 倍以上且收盘价低于开盘价，降杠杆至 **90% SOXX** |
| **破位现金线** | 回撤 -15% | 回撤 -15% | 跌破趋势且回撤较浅时视为下跌陷阱，切换为 **100% 现金 (空仓)** |
| **深坑抄底线 (深跌反弹)** | **回撤 -20%** | **回撤 -40%** | 跌入深坑后博弈反弹：站上 MA20 则 **99% SOXL** 满仓进攻；未站上 MA20 则 **90% SOXX** 防守 |
| **反转冷静期** | >= 1 个交易日 (且 MA20 上行) | >= 2 个交易日 (且 MA20 上行) | 从防守态切回三倍杠杆前的冷却确认，过滤单日假反弹 |

## 3. 触发条件：何时卖出 Covered Call (Trigger Conditions)
只有在以下 **3 个条件同时满足（AND）** 时，才允许卖出 Covered Call：

- [ ] **条件 1（持仓前提）**：当前正按照底层择时规则持有 `SOXL` 正股（持仓数量 $\ge 100$ 股）。
- [ ] **条件 2（短期超涨过滤）**：1 倍半导体指数 ETF（`SOXX`）最近 $5$ 个交易日的累计涨幅 $\ge 5\%$。
  - *逻辑*：短期急速大涨后，接下来一周进入横盘歇息或小幅震荡的概率显著提升。
- [ ] **条件 3（反转初期熔断机制 / 一票否决）**：当前**不处于** `QQQ` 从年线下方重新站上年线后的前 $30$ 个交易日内。
  - *逻辑*：大跌后的第一波大级别反转往往气势如虹，连续暴涨概率极高，此时卖 Call 极易被连续击穿并造成巨额踏空亏损。宁可平时少赚约 $5\%$ 的权利金，也要规避反转初期的暴涨风险。

---

## 4. 合约选择参数 (Contract Parameters)
当触发条件满足，准备开仓（Sell to Open）时，严格按以下参数筛选期权合约：

| 参数维度 | 设定标准 | 逻辑说明 |
| :--- | :--- | :--- |
| **操作方向** | 卖出开仓 (Sell to Open, Call) | 基于手中每 $100$ 股 `SOXL` 卖出 $1$ 张看涨期权 |
| **到期时间 (DTE)** | 约 $1$ 周（$5 \sim 12$ 个自然日） | 只赌暴涨后歇息的那一个星期；时间拉长容易撞上下一波主升浪启动 |
| **行权价选择 (Strike)** | $\Delta \approx 0.20$ | `SOXL` 具有 $3$ 倍杠杆，波动极大，不可按固定百分比（如 $+2\% \sim +5\%$）选行权价。按 $\Delta = 0.20$ 动态适应波动率（历史行权价中位数约比现价高出 $13.8\%$） |

## 5. 平仓与生命周期管理 (Lifecycle & Exit Rules)
开仓后，必须遵循以下平仓铁律（Buy to Close）：

1. **绝不让正股被行权指派（No Assignment）**：
   - 无论期权到期前处于盈利（价外 OTM）还是亏损（价内 ITM）状态，**一律在到期前买回平仓**，绝不把正股交割出去。
2. **到期前一天强制买回（T-1 Rule）**：
   - 在期权到期日的**前一个交易日**，无论合约价格多低、距离行权价多远，全部主动买回平仓（Buy to Close）。
   - *双重优势*：
     1. 规避到期日（周五）当天突发利好导致股价跳空暴涨、由盈转亏的尾部风险。
     2. 提前释放正股担保额度，若当天依然满足开仓触发条件，可无缝衔接卖出下一周的新合约。
3. **正股清仓联动**：
   - 如果在期权持仓期间，底层正股择时规则发出了卖出 `SOXL` 的信号，必须在卖出正股的同时，无条件买回平仓手头的 Call 合约。

## 6. 风险认知与心理建设 (Risk Management)
在执行本技能时，交易者必须明确以下客观事实以保持执行纪律：

1. **盈亏不对称性**：
   - 卖方策略天然具有“赚小钱、亏大钱”的特征（无脑卖时单次平均盈利 $+1.25\%$，单次平均亏损 $-5.4\%$）。必须依靠上述过滤规则将胜率提升至 $80\%$ 以上，并大幅降低被击穿的概率（降至约 $\frac{1}{12}$）。
2. **极端事件冲击**：
   - 若持仓期间遇到周末突发重大宏观利好（如关税暂停等），正股单日暴涨超 $20\%$，单张期权可能造成账户净值回撤 $15\% \sim 17\%$。但因为手里持有正股，正股涨幅通常会覆盖期权亏损，当周账户整体仍为正收益，切忌因单张期权账面浮亏而恐慌违规操作。
3. **策略局限性**：
   - **无法消除大回撤**：Covered Call 收取的权利金无法抵御熊市暴跌，组合最大回撤依然可达 $70\%$ 以上，控制回撤只能靠底层择时规则。
   - **强牛市存在拖累**：在单边极强上涨行情中，卖 Call 依然会少赚一部分上方收益。
